# ramialbatal.github.io

Personal website of Rami Albatal: https://ramialbatal.github.io

The live data clocks linked from the site are separate open projects:
[Emissions Clock](https://github.com/ramialbatal/emissions-clock),
[Renewables Clock](https://github.com/ramialbatal/renewables-clock),
[Jobs Clock](https://github.com/ramialbatal/jobs-clock),
[Peace Clock](https://github.com/ramialbatal/peace-clock) and
[Warming Clock](https://github.com/ramialbatal/warming-clock), built on
[clock-core](https://github.com/ramialbatal/clock-core).
